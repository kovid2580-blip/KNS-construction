# KNS Construction & Real Estate

Official website repository for **KNS Construction & Real Estate** &mdash; *"Building Dreams, Brick By Brick."*

---

## 🏛️ Official Brand Identity Standards

The supplied official logo is the definitive source of truth across all brand collateral and digital platforms.

### Core Brand Elements
* **Typography:** Bold beveled golden serif lettering for "KNS" with navy outline and metallic relief.
* **Crane Graphic:** Tower crane with lattice mast, counterweight boom, trolley, and hook assembly.
* **Building Graphic:** Stepped gold architectural brick block integrated at the base.
* **Tagline:** *"CONSTRUCTION AND REAL ESTATE"* and *"BUILDING DREAMS, BRICK BY BRICK"*.
* **Color Palette:** Brushed architectural gold (`#D4AF37`, `#F4D068`), midnight navy (`#070B14`, `#0D1524`), and slate charcoal.

### Asset Variants in Repository
* `assets/images/kns-logo-full.png` &mdash; Full official emblem with transparent background (used in footer and brand showcase).
* `assets/images/kns-logo-compact.png` &mdash; Compact horizontal lockup with transparent background and subtle 3D depth (used in desktop & mobile navigation).
* `assets/images/kns-crane-mark.png` &mdash; Recognizable architectural crane mark (used for favicons & app badges).
* `favicon.ico` &mdash; Multi-resolution browser favicon.
* `assets/images/apple-touch-icon.png` &mdash; 180&times;180 iOS touch icon.

## 🌐 Pages & Structure

* **`index.html`** &mdash; Homepage featuring Hero, Brand Identity Showcase, Services Grid, Featured Landmarks Portfolio, Interactive Cost Estimator, Trust Badges, and Consultation Request Form.
* **`about.html`** &mdash; Company heritage, structural safety protocols, and heavy machinery fleet.
* **`services.html`** &mdash; Detailed breakdown of commercial, residential villa, real estate advisory, and turnkey interior capabilities.
* **`projects.html`** &mdash; Filterable portfolio with engineering specifications and built-up areas.
* **`contact.html`** &mdash; Corporate office locations, direct helpline, enquiry form, and FAQs.
* **`css/styles.css`** &mdash; Custom responsive design system with 3D logo depth filters and smooth animations.
* **`js/main.js`** &mdash; Interactive real-time cost calculator, portfolio tab filtering, mobile navigation drawer, and form submission modal.

## 🚀 Running Locally

No build step or dependencies required. Run directly with any static server:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js
npx serve .
```

Open `http://localhost:8080` in any modern web browser.
